Image Size Requirements for Instagram, Facebook, X, LinkedIn, TikTok, Pinterest, YouTube, Threads & Bluesky

One shoot, nine platforms, a dozen different pixel dimensions. Here's the current reference table for each — and how to turn one folder of photos into every size at once.

Install Extension

Every social platform crops, scales, or compresses images that don't match its expected dimensions — which is why a photo that looks sharp on your desktop can end up blurry, awkwardly cropped, or padded with empty space once it's posted. Posting the same photo shoot to Instagram, Facebook, X, LinkedIn, TikTok, Pinterest, YouTube, Threads, and Bluesky means matching up to nine different sets of pixel dimensions, often with two or three sizes per platform for profile photos, covers, posts, and stories.

Below is a reference table for each platform's current image sizes, matching the smart presets built into the Bulk Image Resizer Chrome extension. Turning One Shoot Into Every Size at Once

Looking up each of these dimensions and resizing one photo at a time is the slow way to do this. Bulk Image Resizer builds the tables above into its Smart Presets panel: open the extension, select the platform tab (Facebook, Instagram, X, LinkedIn, TikTok, Pinterest, YouTube, Threads, or Bluesky), and check off which image types you need — profile photo, cover, post, story, whatever applies.

  • Batch Processing — select a whole folder of source images and apply multiple presets across every platform in a single pass, instead of resizing and re-exporting file by file.
  • Mix presets with custom sizes — if a client or project needs an exact size not covered above, enter custom width and height alongside the platform presets in the same batch.
  • Multiple Formats — convert to JPG, PNG, or WebP as part of the same resize step, so you're not opening a separate tool afterward.
  • 100% local processing — everything happens directly in your browser tab. Nothing is uploaded to a server, which matters if the images are unreleased campaign assets or client work under embargo.

The practical payoff: a single product photo or campaign graphic can come out the other end as nine (or more) correctly-sized files — one per platform and image type — from one batch operation, in seconds rather than the many minutes it would take to resize and export each size by hand.

Why Matching the Exact Size Matters

Platforms crop what doesn't fit

Upload a square photo to Facebook's cover slot and the platform's auto-crop decides what gets cut off — often a face, logo, or text near the edge.

Upscaling looks worse than resizing

If your source image is smaller than the target dimensions, the platform will stretch it to fit, which introduces visible blur. Starting from a correctly-sized file avoids that entirely.

Consistency reads as more professional

A profile photo that's properly centered and a cover image that isn't awkwardly cropped both signal more polish than a feed of mismatched, auto-cropped images.

One batch instead of nine manual exports

Resizing by hand for nine platforms means nine separate export steps per image. Batch presets collapse that into one operation per shoot.
